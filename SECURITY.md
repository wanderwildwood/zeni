# Security

zeni is wander wildwood's fork of Blockstream Green for E Ink phones. Report a security
problem in it to email@wanderthe.dev. Please leave out private keys, recovery phrases and
anything that identifies a person.

Blockstream does not support this fork. A problem in Blockstream Green's own code, which zeni
carries, can also go to Blockstream, as the SECURITY.md in their repository describes.
